# CLI Turn-Based RPG 2026 — Idea One-Pager

Result of the idea-refine / interview session of 2026-09-27 (confirmed by the author).

## Problem statement

How might we turn two small learning projects (Python 2016, TypeScript 2022) into one didactic, open-source monorepo
where the **same** turn-based RPG is implemented in Python, TypeScript and Go, and is fun enough to play for a long
time?

## Recommended direction

An **endless roguelite** built on the 2016 Python content (Knight, Paladin, Sorcerer, Druid). Rounds are single
fights with a merchant visit after each one; monsters come from ≥ 100 TibiaWiki names in 10 tiers, with a Tibia boss
every 10 rounds and a stronger cycle after the last tier. Loot adds depth (8 equipment slots, 4 rarities, affixes,
elemental protections, crit/dodge/parry/leech); spells level up by use (20 → level 2, 50 → level 3); statuses and
telegraphed boss attacks make choices tactical (Defend).

Everything is data-driven and deterministic: shared JSON, a shared PRNG and golden tests prove the three
implementations are the same game. A headless bot simulator tunes balance and doubles as the full-game e2e test.

## Key assumptions to validate

- [ ] Integer math + mulberry32 give identical results in the three languages → PRNG vectors + golden tests.
- [ ] Textual, Ink and Bubble Tea can render the same 100 × 30 layout with animation → spike each TUI early in its phase.
- [ ] The infinite curve stays fun (runs of 30–80 rounds on NORMAL for a decent player) → simulator reports per
      vocation/difficulty before 1.0.
- [ ] Using Tibia names without sprites is acceptable for a non-commercial, didactic project → note in README.

## MVP scope (per implementation)

Title/language/difficulty/new run/continue, battle with spells/potions/defend, merchant with potions and items,
infinite tiers + bosses, drops with rarities and affixes, spell levels, statuses, auto-save, run history, bestiary,
achievements, Hall of Fame, seeded runs, simulator, full TUI with animated ASCII art, EN + pt-BR.

## Not doing (and why)

- Multiplayer / online ranking — network and servers ×3 languages for little learning value.
- Sound and music — terminal support is inconsistent.
- Locales other than EN and pt-BR — cost ×3 implementations.
- Tibia sprites or original art — copyright; ASCII art is our own.
- Meta-progression between runs (permanent upgrades) — changes the balance model; revisit after 1.0.
- Multiple save slots — one slot is enough for a single local player.
- Item set bonuses — nice to have; post-1.0.

## Open questions

- Python executable (PyInstaller) — not requested; `uv run` is the supported way to play.
