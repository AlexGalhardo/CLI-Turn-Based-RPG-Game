# PLAN — CLI Turn-Based RPG (Python · TypeScript · Go)

Master plan of the project. Check items off (`[x]`) in the same commit that completes them. Rules and formulas are in
[`docs/game-design.md`](docs/game-design.md); decisions in [`docs/adr/`](docs/adr); the confirmed idea in
[`docs/ideas/rpg-2026.md`](docs/ideas/rpg-2026.md).

**Phases:** 1 Python (reference) → 2 TypeScript (port) → 3 Go (port).
**Milestones per phase:** Alpha (clean core) → Beta (all features) → 1.0 refinement (balance, polish, parity).

## Shared content (built during M1–M2, used by every phase)

- [ ] `shared/schemas/*.schema.json` for every data file + `bun run check:shared` (schema + i18n key parity + art format)
- [ ] `balance.json` (difficulties, tiers, scaling, caps, rarity tables, spell levels, magic level curve, merchant, start kit)
- [ ] `vocations.json` (Knight, Paladin, Sorcerer, Druid — values derived from the 2016 game)
- [ ] `spells.json` (3 attack + healing per vocation, Tibia names/incantations, level-3 bonuses)
- [ ] `monsters.json` — ≥ 100 TibiaWiki monsters in 10 tiers with families, attacks, elements, resistances, statuses
- [ ] `bosses.json` — 10 Tibia bosses (one per tier: e.g. Rat King → … → Morgaroth, Ferumbras) with charge attacks
- [ ] `items.json` — TibiaWiki equipment for 8 slots across tiers (weapons per vocation, shields/spellbooks)
- [ ] `affixes.json`, `potions.json` (Health → Supreme, Mana → Ultimate), `statuses.json`, `achievements.json`, `families.json`
- [ ] `shared/art/` — ASCII animations for ~16 families + 10 bosses
- [ ] `shared/i18n/en.json` + `pt-BR.json` (same key set)
- [ ] `shared/golden/` — PRNG vectors + scripted scenarios + bot full runs (generated by Python)

## Phase 1 — Python (reference)

### M1 — Python Alpha (0.2.0): clean core, playable base game

- [ ] uv project (`pyproject.toml`, Python 3.14, Textual, Ruff tabs, mypy strict, pytest + coverage)
- [ ] Domain: PRNG (mulberry32 + helpers), `pct`, enums (element, slot, rarity, stat, phase, difficulty)
- [ ] Domain: definitions (vocation, spell, monster, boss, potion) + run state (player, monster instance)
- [ ] Domain formulas: XP curve (Tibia), magic level curve, melee/spell damage, armor/protection, crit, resistance
- [ ] Infrastructure: JSON data loader with validation, shared dir discovery (`RPG_SHARED_DIR`)
- [ ] Application: engine state machine (merchant → battle → merchant / game over), commands, events
- [ ] Battle: attack, cast (attack/heal), potion, defend, regeneration, victory/defeat, XP, level up, magic level
- [ ] Infinite loop: tiers, cycle scaling, position scaling, boss every 10 rounds, difficulty multipliers
- [ ] Merchant (alpha): buy potions (unlock by round), next fight
- [ ] Temporary plain-text presentation to play the alpha end to end
- [ ] Tests: unit (PRNG vectors, formulas), integration (full fights with seed), coverage ≥ 90% domain/application
- [ ] CI python job green (ruff format --check, ruff check, mypy, pytest)
- [ ] Golden generator (`rpg-golden`) + first golden files (PRNG, scripted fights)

### M2 — Python Beta (0.3.0): all features

- [ ] Items: 8 slots, rarities, affixes, stat aggregation, equip/unequip, bag (20), auto-sell when full
- [ ] Drops: monster chance, boss guaranteed drops, rarity tables, HARD bonus
- [ ] Merchant: sell items, rotating stock, character sheet
- [ ] Elements: weaknesses/resistances, protections, weapon elements
- [ ] Crit, dodge, parry, life/mana leech (with caps)
- [ ] Spell levels by use (20/50) with effect/mana changes and level-3 bonuses
- [ ] Status effects (burn, poison, electrify, bleed, freeze, curse, stun) on both sides
- [ ] Boss pattern: telegraph + charged attack; Defend action
- [ ] Persistence: settings, auto-save at merchant, continue run, atomic writes, schema versions
- [ ] Run statistics (all counters + timestamps + sessions + play time) and history on death
- [ ] Profile: bestiary, achievements, Hall of Fame
- [ ] i18n EN/pt-BR with language selection and difficulty selection
- [ ] Textual TUI: title, language, new run, battle (bars, art, log), spells/potions menus, merchant tabs, game over,
      hall of fame, bestiary, achievements, save & quit
- [ ] ASCII animations (idle/attack/hurt, boss telegraph flash), `--no-anim`
- [ ] CLI flags (`--seed`, `--lang`, `--no-anim`, `--data-dir`, `--simulate`, `--version`)
- [ ] Simulator bot + balance report
- [ ] E2E tests with Textual Pilot (full flow, continue, language, game over) + bot full-run test
