# PLAN — CLI Turn-Based RPG (Python · TypeScript · Go · Rust · Elixir · C++)

Master plan of the project. Check items off (`[x]`) in the same commit that completes them. Rules and formulas are in
[`docs/game-design.md`](docs/game-design.md); decisions in [`docs/adr/`](docs/adr); the confirmed idea in
[`docs/ideas/rpg-2026.md`](docs/ideas/rpg-2026.md).

**Phases:** 1 Python (reference) → 2 TypeScript (port) → 3 Go (port) → 4 Rust, 5 Elixir, 6 C++ (ports).
**Milestones per phase:** Alpha (clean core) → Beta (all features) → 1.0 refinement (balance, polish, parity).

- [x] Infrastructure: JSON data loader with validation, shared dir discovery (`RPG_SHARED_DIR`), i18n translator
- [x] Application: engine state machine (merchant → battle → merchant / game over), commands, events

- [x] Crit, dodge, parry, leech, elemental resistances/protections, statuses (DoT + stun), boss telegraph + charge
- [x] Spell levels by use (20/50) with level-3 bonuses (status chance / cleanse)
- [x] Infinite loop: tiers, cycle scaling, position scaling, boss every 10 rounds, difficulty multipliers
- [x] Merchant: potions (unlock by round), sell, equip/unequip, rotating stock; item factory (rarity + affixes)
- [x] Run statistics counters from events
- [x] Greedy bot + simulator (`uv run rpg --simulate N`) with balance report
- [x] Tests: unit, integration (full bot runs, determinism, save/restore mid-run), golden; coverage ≥ 90%
- [x] CI python job (ruff format --check, ruff check, mypy, pytest) on Linux and Windows
